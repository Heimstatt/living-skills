# Living Checklist — Market Creation and Value Innovation

*Template example. The entries below are illustrative — written to show the format, not real observations. Replace them with your own.*

**Purpose:** Experience layer for applying the market-creation method.

## Entries

### YYYY-MM-DD — Value curve drawn against a single competitor · *illustrative*
**Scope:** Blue Ocean | Strategy canvas
**Insight:** A strategy canvas compared the new offer only with the most visible direct
competitor and ignored substitutes and doing nothing.
**Why it matters:** The curve then shows differentiation inside the existing frame while the
buyer's actual alternatives stay invisible.
**Rule:** Draw the current curve for the alternatives buyers actually use, including substitutes
and nonconsumption, before proposing eliminate/reduce/raise/create moves.

### YYYY-MM-DD — Noncustomers named but not described · *illustrative*
**Scope:** Blue Ocean | Noncustomer tiers
**Insight:** A hypothesis can list noncustomer groups as labels without saying why each one does
not buy today.
**Why it matters:** Without a reason for nonconsumption, the proposed value profile cannot show
which barrier it removes, so the new demand stays an assertion.
**Rule:** For each noncustomer tier, state the reason for nonconsumption and its evidence status,
and link at least one value-curve change to that reason.
